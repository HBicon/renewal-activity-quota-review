换新活动次数限制

配置原型

将多个活动组合为一条次数限制规则，按门店统计成交次数。支持批量导入，所有创建、编辑和启停变更都会写入操作日志。

i
活动 ID 集合、门店日总数量、门店月总数量为必填项。

每个活动只能归属一条规则，停用配置同样占用活动。柜机、App 次数留空时不执行对应限制。成交条件为订单状态“待发货”且付款状态“已付款”。

BULK IMPORT

批量导入规则

按 CSV 格式一次创建多条规则；整批校验通过后才允许导入。

01

导入格式

规则名称、入口次数和状态可留空；活动 ID 集合、门店日总数量、门店月总数量必填。

规则名称,活动ID集合,门店日总数量,门店月总数量,柜机日次数,柜机月次数,App日次数,App月次数,状态

活动 ID 多个时用 | 分隔；状态可填“启用”或“停用”，留空默认启用。空单元格表示不执行对应入口次数限制。
